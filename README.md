## Our Studio — Radial Menu Website
 
Our Studio is a sleek, dark-themed multi-page website built around a unique radial navigation menu. When the center button is clicked, five navigation buttons fan out in a circle with animated connector lines — creating a memorable and interactive user experience. The project is structured with clean separation of concerns across HTML, CSS, and JavaScript files.

## Features
 
- **Radial Navigation Menu:** A central MENU button expands into 5 circular nav buttons arranged in a full 360° radial layout, each connected to the center with animated dashed lines.
- **Two-Column Homepage Layout:** The index page is split into a left column with welcome text and a right column housing the interactive menu — balanced and visually striking.
- **5 Fully Styled Pages:** Each page (Home, About, Contact, Services, Products) has its own unique accent glow color and rich content layout.
- **Premium Visual Design:**
  - Dark theme with a CSS-variable-driven color system
  - Animated dot-grid background and radial glow effects
  - Spring-physics button entrance animations with staggered delays
  - Hamburger icon morphs into an × when the menu is open
  - Pulsing ring animations around the active center button
- **Animated SVG Connector Lines:** Dashed lines are drawn in real time from the center button to each nav button using coordinate-relative SVG rendering — works correctly in any layout.
- **Smooth Page Transitions:** Nav buttons flash with an accent glow before navigating, and each inner page fades in with a slide-up animation on load.
- **White Copyright Footer:** Every page includes a `© 2025 Our Studio` footer — fixed overlay on the index, inline at the bottom of inner pages.
- **Fully Responsive:** Stacks to a single column on mobile screens under 768px.

## Technologies Used
 
- **HTML5:** Semantic structure across all pages with accessibility attributes (`aria-label`, `aria-expanded`).
- **CSS3 (Vanilla):** CSS custom properties (variables), keyframe animations, CSS Grid for the two-column layout, `backdrop-filter` effects, and responsive media queries — zero frameworks.
- **JavaScript (Vanilla):** Handles radial positioning math, SVG line rendering with viewport-relative coordinate correction, open/close state management, staggered animation timing, and client-side page navigation.
